Sitio web personal de **Tazx**, especialista en optimización de sistemas Windows, tweaking de bajo nivel y desarrollo de herramientas de rendimiento.  
Incluye portafolio de proyectos, descarga directa de aplicaciones, información sobre PhantomOS y sección de guías próximamente.

---

## 🧠 Descripción

La web está diseñada con estética *tech / low-level*, simulando un entorno de terminal y código hexadecimal. Su objetivo es presentar los proyectos, habilidades y herramientas de Tazx, además de permitir la descarga directa de scripts y utilidades alojadas en el repositorio.

**Características principales:**
- ✅ Fondo animado con matriz de bytes hexadecimales y código assembly flotante.
- ✅ Preloader con pasos de inicialización.
- ✅ Secciones interactivas con animaciones al hacer scroll.
- ✅ Descarga dinámica de aplicaciones desde la carpeta `Install/` mediante la API de GitHub.
- ✅ Diseño responsive y accesible.
- ✅ Integración con Font Awesome y Google Fonts.
